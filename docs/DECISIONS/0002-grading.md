# ADR-0002 — Deterministic grading
Status: Accepted (proposal), 2026-10-27.
Decision: Server-side versioned mission definitions, deterministic graders, event logging, idempotent attempts and replayable score. AI never grades.
Rationale: fairness, auditability, consistent marks. Bonus points separate from /100 required course score. Hidden answers and correct SQL not shipped to frontend.
