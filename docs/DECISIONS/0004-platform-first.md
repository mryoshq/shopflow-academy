# ADR-0004 — Construire le studio et la plateforme AVANT les cours

Status: Accepted (proposal), 2026-10-27.

Decision: Priorité P0 = schémas/versions, studio enseignant, lecteur étudiant, correction déterministe, dashboards, authentification, suivi et déploiement. Utiliser 2–3 missions de démonstration uniquement pour valider les interfaces. Les 24 activités du parcours du 28 octobre et les autres axes sont ajoutés dans **P2** à partir des supports validés.

Rationale: Découplage du contenu et du code, capacité de modifier un cours dans le navigateur, réutilisation du moteur et développement IA reproductible.

Consequence: aucune obligation de produire les contenus définitifs avant le fonctionnement du studio. On garde le cahier pédagogique comme contrainte de conception future.
