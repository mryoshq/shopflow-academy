## Règles d'usage

- **Variante verte** : mode sombre (en-tête, page de connexion), icône masquable Android, apple-touch-icon et icônes PWA sur fond plein. La favicon reste la version simplifiée (tête seule) ; en mode sombre, elle peut reprendre ces couleurs (sable sur vert).

- **Logo complet** (renard + anneaux) : en-tête, page de connexion, icônes PWA 192 et 512, apple-touch-icon, image de partage.
- **Favicon 16 et 32 px** : version simplifiée dérivée du logo — tête du renard seule, sans anneaux ni points, traits épaissis, pour rester lisible en petit. Garder le dessin et les couleurs.
- **Icône masquable** : symbole dans le cercle central de 80 %, fond uni.
- Mode sombre : fond sombre teinté du thème, contours conservés en vert ou éclaircis si le contraste l'exige (AA).
- Ne pas modifier le dessin du renard ; seuls le recadrage, l'épaisseur des traits et la suppression des anneaux pour les petites tailles sont permis.
