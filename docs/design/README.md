## Règles d'usage

- **Variante verte** : mode sombre (en-tête, page de connexion), icône masquable Android, apple-touch-icon et icônes PWA sur fond plein. La favicon SVG l'utilise en thème sombre.

- **Logo complet** (renard + anneaux) : en-tête, page de connexion, icônes PWA 192 et 512, apple-touch-icon, image de partage.
- **Favicon (SVG, 16 et 32 px)** : le logo complet du propriétaire, sans redessin ni simplification (décision du 28/10/2026) : version sable en thème clair, variante verte en thème sombre.
- **Icône masquable** : symbole dans le cercle central de 80 %, fond uni.
- Mode sombre : fond sombre teinté du thème, contours conservés en vert ou éclaircis si le contraste l'exige (AA).
- Ne pas modifier le dessin du renard ; seuls le recadrage et le redimensionnement sont permis.
