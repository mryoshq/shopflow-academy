# ui-ux

Prioritize a full **teacher course studio** (create/reorder/preview/validate/publish/archive) and generic student mission player BEFORE final courses. Default FR, Moroccan fictitious DH, 1366×768 browser on Windows, teacher on Mac; keyboard/screen-reader, sufficient contrast, clear feedback, not childish. Include empty platform states, drafts, preview not scored, publication errors, no AI, slow network, locked mission, errors and progress. Gamification is optional/private. UI must not expose correct answers or grant points. Run Vitest+Playwright with screenshots for teacher/student flows.
